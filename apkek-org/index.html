What Does APK Mean?

Before discussing Apkek.org further, it helps to understand the term APK.

APK stands for Android Package Kit. It is the package format used by Android for distributing and installing applications.

When an Android application is installed manually rather than through an app marketplace, the installation package is commonly an APK file.

There are legitimate reasons to use APK files. For example, someone might need:

  • An older application version
  • An application unavailable in a particular region
  • A beta release
  • An app distributed directly by its developer
  • Software unavailable through a particular app store

But manual installation also changes the security equation.

The important question is not simply:

“Is this an APK?”

The better question is:

“Where did this APK come from, who published it, and can its authenticity be verified?”

That distinction should be kept in mind whenever an article links to or discusses third-party application downloads.
